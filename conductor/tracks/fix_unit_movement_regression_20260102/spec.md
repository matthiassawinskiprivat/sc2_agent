# Specification: Fix Agent Immobility in Level 3 and 7

## Overview
Following the fix for "Premature Episode Termination," a new regression has been identified where units (Zerglings in Level 3, Roaches/Marines in Level 7) spawn correctly but remain idle. They do not execute move or attack commands despite the environment loop running correctly for the full duration of the episode. This suggests that actions are either not being generated, not being transmitted to the SC2 client, or being overwritten/cleared before the game steps.

## Functional Requirements
- **Restore Unit Mobility:** Ensure that spatial actions generated by the model are correctly translated into SC2 move/attack commands and executed by the units.
- **Action Transmission Integrity:** Verify and fix the mechanism that sends actions to the SC2 client (e.g., `self.do()` or `client.actions()`) to ensure commands are not lost between the `apply_action` call and the next `step()`.
- **Level Consistency:** Ensure the fix applies to both `Level3Bot` and `Level7Bot`.

## Diagnostic Plan (Internal)
1. **Verify Action Generation:** Check if `self._bot.apply_action` is actually being called with non-zero/valid actions.
2. **Trace Command Queue:** Inspect `self._bot._actions` (or `self.actions` depending on the library version) before `client.step()` to see if the commands are queued.
3. **Check State Sync:** Ensure that `_refresh_state` or `_prepare_step` isn't accidentally clearing the command buffer or putting the bot in a state where it thinks it shouldn't act.

## Acceptance Criteria
- [ ] Units in Level 3 move towards their assigned beacons.
- [ ] Units in Level 7 move towards and attack enemies.
- [ ] `ep_rew_mean` in debug training scripts (`debug_train_level_3.py`, `debug_train_level_7.py`) shows positive progress/movement rewards.
- [ ] Integration tests `tests/test_level_3_integration.py` and `tests/test_level_7_integration.py` pass with evidence of unit movement.

## Out of Scope
- Refactoring the reward function again (unless directly related to movement logic).
- Changing the observation space or model architecture.
