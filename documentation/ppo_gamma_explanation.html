Understanding \(\gamma\) (Gamma) in PPO

In Reinforcement Learning, the Discount Factor (\(\gamma\)) determines how much the agent values future rewards compared to immediate ones.

Symbol Reference Guide

Symbol Name Project Usage
\(\gamma\) Gamma Discount Factor: Controls how far the agent "looks ahead." (0.9 = short, 0.99 = long).
\(r_t\) Reward The immediate points (e.g., +20 for beacon, -0.01 for step penalty).
\(G_t\) Return The total sum of all future rewards, discounted by Gamma.
\(\delta_t\) Delta TD-Error: The difference between what we expected and what happened.
\(\lambda\) Lambda GAE Factor: A smoothing parameter (usually 0.95) used to calculate the Advantage reliably.
\(H\) Horizon The effective distance (in steps) the agent can "see."

1. The Goal: Maximizing Expected Return

The agent's goal is to maximize the Discounted Return (\(G_t\)) at each time step \(t\):

\[G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \gamma^3 r_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k r_{t+k}\]

As \(k\) (the number of steps into the future) increases, the reward \(r_{t+k}\) is multiplied by \(\gamma^k\). If \(\gamma\) is small, distant rewards vanish mathematically.

2. The "Effective Horizon"

A useful rule of thumb is the Effective Horizon (\(H\)), which represents roughly how many steps into the future the agent "looks":

\[H \approx \frac{1}{1 - \gamma}\]
Gamma (\(\gamma\)) Effective Horizon (\(H\)) Value after 50 steps (\(\gamma^{50}\))
0.9 ~10 steps \(\approx 0.005\) (Ignored)
0.99 ~100 steps \(\approx 0.605\) (Visible)
0.995 ~200 steps \(\approx 0.778\) (Strong)

3. Impact on PPO and Advantage Calculation

PPO uses Generalized Advantage Estimation (GAE) to decide if an action was "good." The Advantage (\(A_t\)) depends on the TD-error (\(\delta_t\)):

\[\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)\] \[\hat{A}_t = \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \dots\]

If \(\gamma = 0.9\), the Advantage calculation cuts off information from the future very quickly. If your agent needs to walk for 50 steps to reach a beacon, the "Value" of the first step will be 0 because the beacon reward is so heavily discounted that it doesn't "leak back" to the start.

4. The "Goldfish Effect": Credit Assignment

Your intuition is exactly correct: with a low \(\gamma\), the agent might reach the goal, but it won't "know how it got there." This is known as the Credit Assignment Problem.

Imagine the agent takes 50 steps to reach a beacon and gets a reward of \(+1.0\). Let's see how much of that "success signal" reaches the first action taken at Step 1:

\[\text{Signal at Step 50} = 1.0\] \[\text{Signal at Step 1 (with } \gamma=0.9) = 0.9^{49} \approx \mathbf{0.005} \text{ (Vanished)}\] \[\text{Signal at Step 1 (with } \gamma=0.99) = 0.99^{49} \approx \mathbf{0.611} \text{ (Strong)}\]

What happens during training:

  • At Step 1: The PPO update multiplies the gradient by the Advantage. If the Advantage is \(0.005\), the update is effectively zero. The agent learns nothing from that successful episode.
  • At Step 45: The signal is still \(\approx 0.59\). The agent learns that actions taken very close to the beacon are good.

The result: The agent becomes a "Goldfish." It only learns to navigate if it "accidently" starts very close to the goal. It will never learn to cross a map to find a distant objective.

5. Choosing Hyperparameters for SC2

To choose the right values, you should calculate the Optimal Path Time (\(T_{opt}\)) for your map.

Heuristic 1: The Gamma Rule

The Effective Horizon (\(H\)) should be at least as long as the optimal path to the goal.

\[H \geq T_{opt} \implies \gamma \geq 1 - \frac{1}{T_{opt}}\]

Heuristic 2: The Max Steps Rule

Max steps should be 3x to 5x the optimal path time. This gives the agent room to explore without wasting time in "dead-end" episodes.

Map Size Optimal Steps (\(T_{opt}\)) Suggested \(\gamma\) Suggested Max Steps
64x64 ~80 steps 0.99 (H=100) 250
128x128 ~160 steps 0.995 (H=200) 500

6. Conclusion for StarCraft II

StarCraft II is a high-frequency environment. 10 steps (\(\gamma=0.9\)) is often less than 2 seconds of game time. For any navigation task, this is too short.

  • Low Gamma (0.9): The agent is "short-sighted." It only cares about what happens in the next 2-3 seconds.
  • High Gamma (0.99+): The agent is "strategic." It can value a long path that leads to a reward 20-30 seconds later.

Recommendation: Use 0.99 or 0.995 for navigation and unit control.
