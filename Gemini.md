# Project rules
1. For every change set up a strategy and todo list that you can work on. After the strategy is created work on it step by step.
2. This is a complex project. Don't change code that you are not asked to change. Focus on the problem only.
3. Everything should be test-driven. Write test for every implementation step. If a test fails, think about it, if the test should be fixed or the implementation is wrong
4. All existing tests in the project must pass
5. add extensive comments. I want to learn more about reinforcement learning, so a good explanation is always welcome, especially where things become complicated
